# ADR Concatenation

## Overview

All 67 Architecture Decision Records (ADRs) are concatenated into a single markdown file located at ~/Downloads/ADRs.md. <!-- [^4f1ae-67fb0] -->

## Formatting

The concatenated file includes proper markdown headings for each individual ADR. <!-- [^4f1ae-e31d1] -->

## File References

Relative file references within the ADRs are preserved in the concatenated file. <!-- [^4f1ae-e0d4a] -->
