# Media Viewer UI

## Image Viewer

Images in the feed and threads are tappable and open a full-screen viewer with a dark backdrop, dismiss-on-tap, and an xmark close button. Posts with multiple consecutive images render all images in the group, not just the first one. <!-- [^19e07-4] -->
