# GitHub Milestone Phases

## Milestone Phases

GitHub issues are organized into 5 milestones by phase: v1 Blocker, Pre-v1 Hardening, v1 Infrastructure, v1 Developer Experience, and Post-v1. Issues without an assigned phase are bucketed by content: browser-runtime work is assigned to Pre-v1 Hardening, and browser CI work is assigned to v1 Infrastructure. <!-- [^53697-ff4b6] -->
