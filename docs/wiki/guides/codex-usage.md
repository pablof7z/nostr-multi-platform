# Codex Usage Policy

## When Codex Is Consulted

Codex is used sparingly, only at major milestones. Routine slices like the #2388 benchmark methodology are not sent to codex because a single slice is not a milestone. After the #2389 scaffold design pass, codex is consulted for feedback because the scaffold is the foundational binding pattern every later surface migration copies. <!-- [^3c942-92b19] -->
