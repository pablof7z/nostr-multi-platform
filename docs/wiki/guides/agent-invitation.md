# Agent Invitation Criteria and Format

## When to Invite Other Agents

Agents in the tenex-edge fabric should not invite other agents solely because they are available; collaboration should have real payoff — specialization, parallelism, review, continuity, or escalation.

<!-- citations: [^1c293-74e37] [^1c293-644c3] -->
## What a Useful Invitation Includes

A useful agent invitation names the work, the expected output, and the channel context.
