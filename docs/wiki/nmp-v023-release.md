# NMP v0.2.3 Release

## nmp v0.2.3 Release

The nmp_v0.2.3 release includes the NIP-42 auth race fix (handle_reconnect on Authenticated), the generic open_interest FFI replacing open_author/open_thread/open_firehose_tag, removal of PublishNote in favor of PublishRaw{kind:1}, a unified AddSigner API, and cleanup of the legacy TimelineItem cluster.
