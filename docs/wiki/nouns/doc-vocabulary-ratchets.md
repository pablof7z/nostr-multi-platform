# doc/vocabulary ratchets

CI lint gates that stop old register_defaults/raw-projection vocabulary from creeping back into docs and code. They are pro-migration — the opposite of friction-for-nothing — enforcing the clean-break by failing CI if old vocabulary re-enters.
