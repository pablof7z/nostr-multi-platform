# pre-v1

Defined by #2690's exit criteria — issues that must be completed and proven before the v1 publish act. In this session, only #2690 (the release train itself) and #2711 (upstream-blocked RUSTSEC) carry the pre-v1 label; all other open issues were ruled post-v1.
