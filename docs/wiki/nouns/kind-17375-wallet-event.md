# kind:17375 wallet event

The NIP-60 encrypted wallet configuration event — stores the wallet's Cashu private key and the list of mint URLs, encrypted with NIP-44 keyed to the owner's pubkey. Its relay tags were demoted from authoritative relay selection to a non-authoritative legacy hint; NIP-65 fallback is the design doc's authoritative source.
