# kind:17375

NIP-60 wallet configuration event — encrypted with NIP-44 keyed to the owner's pubkey, stores the wallet's Cashu private key and the list of mint URLs. Its `relay` tags are demoted to a non-authoritative legacy hint (renamed `legacy_relay_hint`); kind:10019 + NIP-65 fallback is the authoritative relay source.
