# ConceptRead

A three-stage read lifecycle: (1) Demand — what events/resources must be alive; (2) Admission + model — which matching facts matter and how they update state; (3) Output — what typed data is emitted to the host. The internal pattern concept owners parameterize, never exposed as a universal public trait.
