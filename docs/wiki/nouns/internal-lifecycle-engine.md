# internal lifecycle engine

A small internal engine with optional hooks for exceptional concept-owned phases — the genericity that #2508 rejected at the public surface moves one layer below it. Owns handle registry, replay-before-live, live activation, exact-demand withdrawal, reverse teardown, tombstoning, coalesced emission. Not a god-trait.
