# Trellis

A private reconciliation substrate below typed read sessions. Trellis owns generic mechanics (graph transactions, dependency identity, collection diffs, scoped teardown, output-frame lifecycle, deterministic replay); NMP owns Nostr and product meaning. Its graphs are in-memory, per-session, and die with the process — trellis-core has zero persistence.
