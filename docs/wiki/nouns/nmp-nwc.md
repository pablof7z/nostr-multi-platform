# nmp-nwc

The NIP-47 Nostr Wallet Connect codec crate — owns URI parsing, NIP-44 encrypted request/response, kind:23194 builder, and kind:23195 decoder. Distinct from nmp-nip47 which owns the wallet runtime; nmp-nip47 depends on nmp-nwc.
