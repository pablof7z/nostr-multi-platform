# one internal engine

The public surface has many concept-shaped doors (open_feed, open_replies, etc.), but there is exactly one implementation of the lifecycle skeleton; each concept owner supplies only its semantic parameters (demand, admission, reducer, output), never the lifecycle mechanics.
