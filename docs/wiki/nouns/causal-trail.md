# causal trail

An in-memory, annotated delta log answering 'why is the wallet state this shape' — a bounded time-ordered ring of post-observation facts (token added/deleted, mint probe verdicts, nutzap redeemed, saga transitions) plus a per-atom last-cause index; rebuildable, non-money-critical, never a rebuild authority
