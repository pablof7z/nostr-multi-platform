# Component-Owned Claiming

## Component-Owned Claiming

Components self-claim the profiles they need (e.g. an article embed claims the article author's kind:0). The kernel never fetches kind:0 off an event on ingest; profile fetching is always the concern of the presentation layer via component-owned claiming. [^6a951-6]
